# Responsive Flex Layout

This webpage demonstrates basic flexible web design principles.

When the screen is wide enough to fit two columns across horizontally, a media query for that width will change the layout of the columns. In this view, each column will take up 49% of the space on the row with the remaining 2% of space in-between them.

Once the browser viewport is wide enough and the website layout changes, the layout inside of the columns will change too. Instead of being beside the text, the images will be on top (i.e. like a polaroid photo) with the text below. The images are flexible, responsive, and they are not larger than the container element they are in.
